Palette

Colors are named by role. A page writes the token, never the value, and dark mode swaps the value underneath. One accent per screen, and at most two accent-colored elements above the fold.

Surfaces and ink

Page background.
--surface
Cards, sheets, table bodies.
--surface-2
Table header rows, input fields, hover rows.
--ink
Primary text and headline numbers.
--ink-2
Descriptions and secondary table cells.
--muted
Labels, axis text, captions, disabled text.
--line
Hairline dividers and chart gridlines.
--line-2
Input outlines and card edges where space is not enough.

--accent
The one interactive color: primary button, selected item, focus ring.
--accent-ink
Text on an accent fill.
--accent-wash
Selected row and selected rail item background.
Delta and status

--neg
Adverse delta; Breach status.

--stale

--pos-wash and the other washes
Chip and cell backgrounds, the matching status hue at .12 alpha.

Sequential ramp
--seq-1--seq-2--seq-3--seq-4--seq-5--seq-6--seq-7

Heatmaps and ordered bins. --seq-1 is the lowest magnitude; --seq-7 is always the highest-contrast end against the background, so the ramp reverses in dark mode.

Buttons

Buttons are verbs. One primary button per screen; it takes the accent. Everything else is the default or the quiet button.

.btn .btn-primary
The one action the screen exists for.
.btn
Secondary actions that stay visible.
.btn .btn-quiet
Dismissals and low-weight actions beside a primary.
.btn:disabled
Unavailable until a second run exists.
.btn .btn-quiet .btn-icon
An icon only where it is the control, with an accessible name.

Cards

A card groups one subject on the surface color. The edge is a hairline and the lightest shadow; the content inside is separated by space.

Sheet

A sheet edits one object without leaving the page. It slides in from the right over the content, carries its own primary action, and closes on Escape or Cancel.

Behavior Opens and closes in --t-base, 200ms. Radius --r-3, elevation --shadow-2, width 400px. The footer holds the actions: the primary on the right, Cancel beside it. Field labels are nouns; the primary button names what happens.

Charts

No gridlines except a zero line where negative values exist, and no y-axis. The SVG carries marks only and stretches to the card; the unit above and the category labels below are HTML text, so they never scale under 12px. Headline values sit as chips beside the title, a single-series chart is neutral with the base darker, and every chart keeps its source caption and a table view. Hover a mark for its value. All three plot run run-20260923-163546-001557f.
